# Catalog

รายการที่ผ่านการตรวจสอบและได้คะแนนอย่างน้อย 70/100 แยกตามประเภทของทรัพยากร

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `repositories/` | Repository สำหรับ Vibe Coding และ AI Coding |
| `system-prompts/` | System Prompt และ Agent Prompt |
| `cursor-rules/` | `.cursor/rules/*.mdc` และ `.cursorrules` |
| `agent-instructions/` | `AGENTS.md`, `CLAUDE.md` และคำสั่งสำหรับ Coding Agent |
| `app-templates/` | App Template, Starter Kit และ Boilerplate |
| `workflows/` | Workflow, Skill, MCP และ Automation Template |

## สถานะ

- **แนะนำ** — ผ่านเกณฑ์และข้อมูลสำคัญได้รับการยืนยัน
- **ควรตรวจเพิ่ม** — มีคุณค่าแต่ยังมีประเด็นที่ต้องตรวจสอบก่อนใช้งานจริง
- **ไม่แนะนำ** — ไม่ผ่านเกณฑ์และจะไม่บันทึกเป็นรายการใน Catalog

แต่ละไฟล์ต้องใช้โครงสร้างจาก [ENTRY_TEMPLATE.md](../templates/ENTRY_TEMPLATE.md)
