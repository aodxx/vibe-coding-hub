# Project Kit Template

สร้างโฟลเดอร์ kits/lowercase-kebab-case/ โดยต้องมี kit.json, README.md, QUICKSTART.md, AI-BUILD-PROMPT.md, LICENSE, docs/ARCHITECTURE.md, docs/SECURITY.md และ starter code

## Definition of Ready

- ปัญหา กลุ่มผู้ใช้ และขอบเขต MVP ชัดเจน
- เลือกสถาปัตยกรรมหลักหนึ่งแบบ
- ระบุบัญชี บริการ และค่าที่ผู้ใช้ต้องสร้างเอง

## Definition of Done

- Starter code เริ่มทำงานได้หลังกรอกค่าตั้งค่า
- Backend ตรวจสิทธิ์และ validate ข้อมูล
- ไม่มี Secret ใน Repository
- มี Loading, Empty, Error และ Success states
- Setup, Deploy, Security และ AI prompt ตรงกับโค้ดจริง
- npm test และ npm run build ผ่าน
